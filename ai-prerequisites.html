Prerequisites for AI Features

Before using the AI features, configure the required database privileges and network access for the database account that connects to the generative AI service.

These prerequisites apply to the following capabilities:

  • AI-powered help assistant
  • Natural-language data queries
  • AI-assisted calculation scripting
  • Model Context Protocol (MCP) server integration
